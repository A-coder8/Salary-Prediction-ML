# پیش‌بینی حقوق با یادگیری ماشین 💰🤖

**زبان:** [🇬🇧 English](README.md)

این پروژه یک مدل یادگیری ماشین از نوع **Regression** است که با استفاده از اطلاعات شخصی و شغلی افراد، حقوق آن‌ها را پیش‌بینی می‌کند.

## 📌 ویژگی‌های ورودی

مدل از ویژگی‌های زیر استفاده می‌کند:

- سن
- میزان سابقه کاری
- سطح تحصیلات
- سطح شغلی
- ساعات کاری هفتگی
- شهر

متغیر هدف:

- حقوق (Salary)

## 🧠 مدل و ابزارهای استفاده‌شده

در این پروژه از موارد زیر استفاده شده است:

- `Pandas` برای پردازش داده‌ها
- `Scikit-learn` برای یادگیری ماشین
- `Linear Regression` برای رگرسیون خطی
- `PolynomialFeatures` برای ایجاد ویژگی‌های چندجمله‌ای
- `pd.get_dummies()` برای تبدیل داده‌های دسته‌ای به ویژگی‌های عددی

## 📊 دیتاست

این پروژه شامل یک دیتاست مصنوعی با **۱۰۰۰ رکورد** است.

ستون‌های دیتاست:

```text
age
experience_years
education
job_level
weekly_hours
city
salary
```

## 🔮 پیش‌بینی با داده‌های دستی

این پروژه امکان وارد کردن اطلاعات یک فرد به‌صورت دستی و پیش‌بینی حقوق او را نیز دارد.

برای مثال:

```text
Enter age: 25
Enter experience_years: 3
Enter education: Bachelor
Enter Job level: Junior
Enter weekly_hours: 40
Enter City: Tabriz

Model answer: ...
```

## ⚠️ توجه

دیتاست استفاده‌شده در این پروژه **مصنوعی** است و فقط برای تمرین یادگیری ماشین ساخته شده است.

مقادیر حقوق موجود در این دیتاست نشان‌دهنده آمار واقعی حقوق در دنیای واقعی نیستند.
